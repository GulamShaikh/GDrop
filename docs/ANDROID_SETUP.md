# Android setup

This project keeps the backend in Python and adds a minimal Android app under `android/GDrop`.

## Prerequisites

- Android Studio
- Android SDK 34
- Java 17

## Build

Open the project in Android Studio and run the `app` configuration on a device or emulator.

## Notes

The app is intentionally minimal and focuses on receiving files from the existing GDrop laptop server over the local Wi‑Fi network.
